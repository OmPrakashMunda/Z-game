# Controls

## Keyboard
| Key | Action |
| --- | --- |
| `W` `A` `S` `D`, arrow keys | Walk (up the screen is forward). While driving: gas, brake, steer |
| `Shift` | Run. While driving: handbrake |
| `Space` | Use: go in at a shop door, get in or out of a vehicle, search a house |
| `Q` / `E` | Turn the view left / right (hold) |
| `Z` / `C` | Tilt the view toward the side / toward straight down (hold) |
| `I` | Storage list |
| `O` | Orders |
| `N` | News |
| `B` | Online store |
| `V` | Open storage to place something |
| `R` | Rotate what you are placing, or the structure you have selected (instant) |
| `1` to `9` | While placing: switch to the 1st to 9th structure in your storage |
| `P` | Base Architect |
| `U` | Show or hide every power cable and water pipe |
| `F` | Fast-forward (4x) on or off |
| `M` | Mute |
| `` ` `` | Cheat box |
| `Esc` | Stop placing, then close a card or list, then open the menu |

Typing in a text box never triggers a game key.

## Mouse
| Action | Result |
| --- | --- |
| Left-drag | Look around (the camera follows you again as soon as you move) |
| Middle-drag | Look around |
| Right-drag sideways | Turn the view |
| Right-drag up or down | Tilt the view |
| Wheel | Zoom toward the pointer |
| Click a shop or plot | Its card: how far away it is, and a button to set a waypoint (or to go in, if you are at the door) |
| Click a vehicle | Its card: fuel, repairs, parts, cargo |
| Click a placed structure | Open its card |
| Click your name on the left | Open the character panel: warmth, dryness, and the five clothing slots (Wear and Take off) |
| Click the corner map | Set a waypoint |
| While placing: click | Place it |
| While placing: drag | Lay a line (fences, walls, hedges, paths, spikes, trenches) |

## Top bar
From left to right: day and countdown, phase tag, clock, the season with the temperature and sky, money, where you are, your waypoint (if any), what your
backpack holds (if anything), a **Cheats** tag when any cheat is on, then the view buttons (turn left, compass, turn right,
tilt up, tilt down, cables and pipes), the speed buttons, sound and the menu.

The compass needle points north. Click it to reset both turn and tilt.

## Bottom of the screen
The dock in the bottom left corner (Build, Online store, Storage, Orders, News), the driving display while you drive, and the
corner map on the right.

## Top right
A box says what `Space` would do right now, for example "Space  Roadside Motel" at a shop door or "Search the bungalow" at a house. It
is only there when `Space` would do something.

## Gamepad

Plug in a controller (Xbox, PlayStation, Switch Pro and most others with the standard layout) and press a button: the game says
"Gamepad connected". The keyboard and mouse keep working at the same time.

| Control | Action |
| --- | --- |
| Left stick | Walk. While driving: steer (and up and down work the pedals) |
| Right trigger | Gas |
| Left trigger | Brake, and reverse |
| Left stick press | Run. While driving: handbrake |
| `A` | Use: go in at a shop door, get in or out of a vehicle, search a house (same as `Space`) |
| `B` | Back: close what is open, then open the menu (same as `Esc`) |
| `X` | Storage list (`I`) |
| `Y` | Online store (`B`) |
| `Start` | Menu (`Esc`) |
| `Select` | Fast-forward on or off (`F`) |
| `LB` / `RB` | Turn the view left / right (`Q` / `E`) |
| Right stick | Left and right turn the view, up and down tilt it (`Z` / `C`) |
| Right stick press | Reset the view |
| D-pad up / down | Zoom in / out |

**In a menu** (the title screens, the pause menu, shops, lists) the left stick and the D-pad move a highlight between the
buttons, `A` presses the highlighted one, and `B` goes back. Sliders change with left and right. Typing a name still needs a
keyboard.

Placing structures and clicking things in the world still need the mouse. A controller that supports it shakes when a vehicle
crashes.
