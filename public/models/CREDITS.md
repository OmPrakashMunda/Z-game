# Asset credits

All 3D models in the game so far are generated in code (`src/render/models.ts`) from basic shapes.
No third-party assets are used yet.

When free packs are added (for example Kenney or Quaternius, which are CC0), list each pack here with its
author, source URL and license, and confirm the license before using any model.

## Icons

UI icons come from Lucide (https://lucide.dev), ISC license, installed from the lucide npm package.
